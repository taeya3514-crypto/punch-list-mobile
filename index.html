❓ 사용방법 (모바일 2호)

  1. 등록 — 오른쪽 아래 ＋ 버튼. 사진부터 찍고 나머지 항목은 나중에 채워도 됩니다.
  2. 즉시 저장 — 저장을 누르면 화면엔 바로 반영되고, 실제 서버 저장은 뒤에서 자동으로 진행됩니다.
  3. 동기화 상태 — 카드에 "저장 대기중/동기화중/실패" 표시가 뜨면 아직 서버에 완전히 반영되지 않은 것입니다. "실패"는 탭하면 다시 시도합니다.
  4. 오프라인 — 인터넷이 끊겨도 등록/수정은 계속 가능하고, 연결되면 자동으로 밀린 저장이 진행됩니다. 화면을 새로고침해도 대기 중인 저장 내용은 유지됩니다.
  5. 사진 — 시공 전/후 사진을 각각 촬영하거나 파일로 선택. 상세보기에서 사진을 탭하면 원본 크기로 확대됩니다.
  6. 1호와의 차이 — 이 화면은 모바일 터치 전용 카드 화면입니다. PC용 표 화면(다현장·엑셀 내보내기 등)은 기존 1호를 그대로 이용하세요.
